waiting for the first event

Every connection the observer has reported an event for, built in this page from the event stream: a connection appears with its first event and goes when its session ends. The last column is the kernel's smoothed round trip; hover it for the rest of the TCP sample. Only the rows in view are rendered, so the table stays usable at tens of thousands of connections. Counting block announcements means one message per connection per block: it is off by default. A spinner means no message has carried that value yet. A greyed row is a connection that was already open when this page connected: its handshake is in the past, so those columns stay empty.
